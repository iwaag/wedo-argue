# A question to the requester is the run's own question

**Finding.** When the conductor needs the requester's intent, the question
is recorded on the conductor's own run (`wfe discussion talk`), so the
answer is delivered to the run that waits for it.

**Sources.** argue p3 ex1 (`argue-p3-ex1-trial` #191–#192):
`argue/facilitate/run-009` asked the Developer in a synthesis, made its node
wait on the discussion, and ended; the answer #192 started run-010, and
run-009 waited until Omni cancelled it (devdocs
`episodes/argue/p3/ex1/report.md`, *Limitations*).

**Status.** Adopted with argue p4 (WFE routes an untargeted reply to the
conductor's open question).
